export-kit

Save text, JSON, CSV and binary to the user's device — and bundle files into a store-only ZIP. One file, no dependencies. MIT.

Try the demo Source

Save anything

Export.text, .json, .csv, .blob — the Blob → URL → <a download> dance, once.

Bundle into a ZIP

Export.zip(files) writes a store-only archive readable by every unzip tool. No dependencies.

Pure and testable

Export.zip runs in Node — build a ZIP, read it back, check the CRCs.

Offline-first

No network, no CDN, no telemetry. Works from file:// and GitHub Pages.

Sits beside web-kit (CSV, storage) and above compress-kit (gzip/deflate).
